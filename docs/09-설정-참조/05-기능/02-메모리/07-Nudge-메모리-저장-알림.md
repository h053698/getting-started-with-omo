#### Nudge: 메모리 저장 알림

장기적으로 보존할 사실이 아직 기록되지 않았다면 에이전트에게 저장하도록 상기시킵니다.

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `nudge.enabled` | `true` | 메모리 메타데이터 블록에 Nudge 문구를 출력합니다. |
| `nudge.every_user_turns` | `10` | 저장 없이 지정된 수만큼 사용자 턴이 지나면 Nudge를 표시합니다. |
