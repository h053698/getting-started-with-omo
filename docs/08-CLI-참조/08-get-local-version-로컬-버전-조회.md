## get-local-version: 로컬 버전 조회

로컬 플러그인의 버전과 업데이트 상태를 표시합니다.

### 로컬 버전 조회 사용법

```bash
bunx oh-my-openagent get-local-version
```

### 로컬 버전 조회 옵션

| 옵션 | 설명 |
| --- | --- |
| `-d, --directory <path>` | 플러그인/설정 감지에 사용할 작업 디렉터리 |
| `--json` | 스크립트에서 사용할 수 있도록 JSON으로 출력 |
