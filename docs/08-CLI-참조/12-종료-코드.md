## 종료 코드

- 성공 시 `0`
- 실패 시 `1`
- boulder 상태 파일이 존재하지만 읽을 수 없으면 `2`
- `run`이 중단되면 `130`

`run`, `install`, `uninstall`/`cleanup`, `doctor`, `get-local-version`,
`refresh-model-capabilities`, config
migrate`,`boulder`,`ulw-loop` 및 `mcp oauth` 하위
명령은 명시적인 숫자 종료 코드를 반환합니다.
