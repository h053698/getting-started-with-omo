## 어떤 에디션을 선택해야 하나요?

**Ultimate**: 이미 OpenCode를 사용하거나 가장 충분히 테스트된 설치 경로를 원한다면 선택하세요.

```bash
bunx oh-my-openagent install
```

**Light**: 이미 Codex CLI를 사용한다면 선택하세요.

```bash
npx lazycodex-ai install
```

**OmO Native**: 호스트를 먼저 설치하지 않고 명령 하나로 시작하려면 선택하세요.

```bash
curl -fsSL https://get.omo.dev/install.sh | bash
```

<details>
<summary>Windows 또는 bun으로 설치</summary>

```powershell
irm https://get.omo.dev/install.ps1 | iex
```

```bash
bun add -g omo-ai
```

</details>

Ultimate와 Light는 이미 실행 중인 호스트에 로드하는 플러그인입니다. OmO Native는 OMO가 내장된 고정된
Senpi 엔진을 제공하는 독립형 에디션입니다.

> [!WARNING]
> OmO Native를 사용하려면 `omo-ai`를 설치하세요. npm에서 일반 `omo`를 설치하지 마세요. 다른 작성자가 만든 관련 없는 패키지입니다.
